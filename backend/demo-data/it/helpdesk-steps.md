# IT Helpdesk Steps (Demo/Fictional)

For any IT issue (laptop, desktop, printer, network, email), first check the Self-Help Knowledge Base on the intranet. If unresolved, raise a ticket under category "IT - Hardware", "IT - Software", or "IT - Network".

Standard resolution timelines:
- Password reset / account lockout: within 2 hours
- Hardware issues (laptop/desktop/printer): within 1 working day
- Network/connectivity issues: within 4 hours
- New software installation request: within 3 working days, subject to license approval

Password reset self-service is available via the "Forgot Password" link on the login page using your registered mobile number or backup email.

Critical outages affecting an entire office/floor should be reported by phone to the IT helpdesk hotline in addition to raising a ticket, for priority handling.
