# API Reference (Summary)

Full interactive OpenAPI docs are auto-generated by FastAPI at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`
- Raw schema: `http://localhost:8000/openapi.json`

This file is a human-readable summary for the report/viva.

## Auth (`/api/auth`)
| Method | Path | Role required | Description |
|---|---|---|---|
| POST | `/register` | none | Create a new user |
| POST | `/login` | none | Get a JWT access token |
| GET | `/me` | any authenticated | Current user's profile |

## Departments (`/api/departments`)
| Method | Path | Role required | Description |
|---|---|---|---|
| GET | `` | any authenticated | List all departments |
| POST | `` | super_admin | Create a department |

## Documents (`/api/documents`)
| Method | Path | Role required | Description |
|---|---|---|---|
| GET | `?department_id=` | own department, dept_admin, super_admin | List documents |
| POST | `/upload?department_id=&title=` | dept_admin | Upload + ingest a PDF/TXT/MD file |
| DELETE | `/{id}` | dept_admin | Remove a document and its vectors |

## Chat / RAG (`/api/chat`)
| Method | Path | Role required | Description |
|---|---|---|---|
| POST | `/ask` | any authenticated (own department) | Ask a question, get a source-cited answer |
| GET | `/history?department_id=` | any authenticated | Your own chat history |
| POST | `/feedback` | any authenticated | Thumbs up/down on an answer |

## Tickets (`/api/tickets`)
| Method | Path | Role required | Description |
|---|---|---|---|
| POST | `` | any authenticated (own department) | Raise a ticket |
| GET | `?status=` | any authenticated (scoped by role) | List visible tickets |
| GET | `/{id}` | any authenticated (scoped by role) | Ticket detail + comments |
| POST | `/{id}/assign` | dept_admin | Assign ticket to an officer |
| POST | `/{id}/comments` | any authenticated (scoped); only officer/admin can change status | Add comment / change status |

## Dashboard (`/api/dashboard`)
| Method | Path | Role required | Description |
|---|---|---|---|
| GET | `/analytics?department_id=` | officer, dept_admin, super_admin | Tickets by status/category, common questions |

## Admin (`/api/admin`)
| Method | Path | Role required | Description |
|---|---|---|---|
| GET | `/audit-logs?limit=` | super_admin | View audit log |
| GET | `/users?department_id=` | dept_admin (own dept), super_admin | List users |
| PATCH | `/users/{id}/role?role=` | super_admin | Change a user's role |
| PATCH | `/users/{id}/toggle-active` | super_admin | Enable/disable an account |

## Auth header
All authenticated endpoints expect:
```
Authorization: Bearer <access_token>
```
Tokens are obtained from `/api/auth/login` and expire after
`ACCESS_TOKEN_EXPIRE_MINUTES` (default 480 minutes / 8 hours).
